# Installing Spacecraft Software Theme for iTerm2

**Version:** 2.0 | **Author:** Mohamed Hammad | **License:** GPL-3.0-or-later | **Website:** [SpacecraftSoftware.org](https://SpacecraftSoftware.org)

## Installation

Each theme in the Steelbore palette family ships as its own colour preset
under `themes/`, named by slug: `themes/<slug>.itermcolors`.

1. Pick a theme from the table below and double-click its
   `themes/<slug>.itermcolors` file — iTerm2 imports it automatically.
   *Or* go to **iTerm2** → **Preferences** → **Profiles** → **Colors** →
   **Color Presets…** → **Import…** and select the file from `themes/`.
2. Select its name from the **Color Presets** dropdown to apply it to the
   current profile.
3. Repeat for any other themes you want available — iTerm2 keeps every
   imported preset in the dropdown, so you can switch freely.

## Choosing a theme

`steelbore` is the default and the one to start with. Every dark theme has a
`-high-contrast` sibling (§11.1.1) that widens contrast for low-vision and
bright-environment use — same palette, same hues, stronger separation. The
two `solarized-*` themes are the §11.5 **fidelity palette**: Solarized is
reproduced verbatim for users who want it pixel-for-pixel, and is
intentionally **non-conforming** — it is not a Spacecraft Software brand
palette and should not be treated as one.
