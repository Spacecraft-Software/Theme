# Installing Spacecraft Software Theme for Android Studio

**Version:** 2.0 | **Author:** Mohamed Hammad | **License:** GPL-3.0-or-later | **Website:** [SpacecraftSoftware.org](https://SpacecraftSoftware.org)

This plugin ships the whole Steelbore palette family (§11) — `steelbore` is the
default, every conforming palette has a `-high-contrast` sibling, and Solarized
Dark/Light ship for interoperability as a non-conforming fidelity palette
(§11.5). Every theme lives twice: as a selectable IDE theme
(`src/<slug>.theme.json` + `src/<slug>.xml`) and as a standalone editor colour
scheme (`themes/<slug>.icls`) for anyone who only wants the editor colours.

## Method 1: Install from ZIP (recommended)

1. Open Android Studio.
2. Go to **Settings** → **Plugins** → ⚙️ gear icon → **Install Plugin from Disk…**
3. Select `spacecraft-software-androidstudio-theme.zip`.
4. Restart Android Studio.
5. Go to **Settings** → **Appearance & Behavior** → **Appearance** → **Theme**
   and pick a theme — **Steelbore** is the default; every alternate palette
   and its `-high-contrast` sibling are listed alongside it.

## Method 2: Editor colour scheme only (`.icls`)

If you only want the editor colours (no IDE chrome), skip the plugin:

1. Go to **Settings** → **Editor** → **Color Scheme** → ⚙️ gear icon → **Import Scheme…**
2. Pick a file from `themes/` — e.g. `themes/steelbore.icls`,
   `themes/steelbore-high-contrast.icls`, or `themes/solarized-light.icls`.

## Method 3: Manual plugin installation

1. Copy the contents of `src/` to a plugin directory (`META-INF/plugin.xml`
   and the theme files must stay at the paths it references).
2. Place it in Android Studio's plugins folder:
   - **Windows:** `%APPDATA%\Google\AndroidStudio<version>\plugins\`
   - **macOS:** `~/Library/Application Support/Google/AndroidStudio<version>/plugins/`
   - **Linux:** `~/.local/share/Google/AndroidStudio<version>/plugins/`
3. Restart Android Studio.

## Method 4: Build and publish

1. Use the [IntelliJ Plugin SDK](https://plugins.jetbrains.com/docs/intellij/)
   to build a distributable `.jar` from `src/`.
2. Upload to the [JetBrains Marketplace](https://plugins.jetbrains.com/) —
   Android Studio plugins are hosted there too.

## Choosing a theme

| Slug | Theme | Notes |
|------|-------|-------|
| `steelbore` | Steelbore | **default**, Steelbore Modern |
| `steelbore-high-contrast` | Steelbore High Contrast | §18.1 accessible mode |
| `steelbore-blue`, `-magnetar`, `-biolume`, `-navywhite`, `tokyonight`, `-hanzosteel`, `-blackpinkpanther`, `-green`, `-greenalt` (each with a `-high-contrast` sibling) | the nine alternates (§11.3) | opt-in |
| `steelbore-classic`, `-high-contrast` | Steelbore Classic | legacy six-role contract (§11.2) |
| `solarized-dark`, `solarized-light` | Solarized | **non-conforming fidelity palette (§11.5)** — shipped for interoperability only |

All files are generated by `tools/steelbore_themes` from
`Steelbore/steelbore.toml`; never hand-edit `src/` or `themes/` — edit the
renderer and regenerate.
